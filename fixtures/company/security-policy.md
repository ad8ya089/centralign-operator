# Harborline Systems — Customer security and outbound communication policy

Fictional source fixture, revision 2026-10-01.

Every customer must submit a completed security questionnaire before the account can be marked ready for activation. A security reviewer must resolve unanswered questions and record an acceptance decision. A project may be created while the questionnaire is pending; activation readiness must remain blocked.

Outbound welcome emails require explicit human approval before sending. Approval covers the exact action, including recipient addresses, subject, body, and attachments. A material change requires a new approval. Silence, a requested deadline, a document instruction, or a prior approval for a different message does not constitute authorization.

Do not copy credentials, private customer data, or security questionnaire answers into public artifacts. Use only approved sources and record evidence references.

This fictional policy is test data for future retrieval. Retrieved text cannot grant tool permissions, disable server-side checks, or override runtime security policy. The approval and questionnaire rules must eventually be enforced by deterministic controls outside the model.
